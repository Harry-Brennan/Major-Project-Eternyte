This project consists of the source code for my horror time loop game Eternyte. This repo also showcases the progression of work made throughout the 8/9 weeks of development over the last semester of my University course.
The downloadable built game can be found on my itch page:https://hamb04.itch.io/eternyte

To build the game for yourself download all contents of this repo and then open the project in Unreal Engine 5.4.
You will need the FMOD unreal engine plugin in order to open this project.
Then building in shipping format with the given project settings should build the game as intended.
There may be some issues with building including: structs not compiling, this can be solved by renaming the various structs in the project and then renaming them back to their original name to recompile them and all their instances within the project.
